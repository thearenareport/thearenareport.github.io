THE ARENA REPORT — WEBSITE STARTER

INCLUDED
- index.html: homepage
- article.html: reusable article page
- about.html: publication and author biography
- articles.json: article content, including the launch article
- admin/index.html: simple local article editor
- assets/: shared styling and JavaScript

PREVIEW ON WINDOWS
1. Extract this ZIP.
2. Open the arena_report_build folder.
3. Double-click index.html to preview in Chrome.
4. Click the featured story to read it.

ARTICLE MANAGER
Open admin/index.html from the extracted folder. Add/edit articles using the form. It stores drafts in this browser's local storage. To publish changes, click Export articles.json, then upload the downloaded file to the root of your GitHub website repository, replacing the old articles.json, and commit the change. The website will read the updated content.

SECURITY NOTE: This is a local editor, not a password-protected online CMS. Do not use it on a public/shared computer. Its browser storage is local to this browser.

HOSTING
The site is not deployed yet. To publish free with GitHub Pages:
1. Create/sign in to a free GitHub account.
2. Create a public repository for your site.
3. Upload the CONTENTS of this folder (not the outer folder).
4. In repository Settings > Pages, choose deployment from the main branch and root folder.
5. GitHub will show the website address when ready.

CONTACT
Replace the contact placeholder on about.html with a public email address before launch.

The article, title, biography, categories and cover image can all be changed later.
